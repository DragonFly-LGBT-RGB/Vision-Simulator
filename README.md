# Симулятор зрения

Одностраничный сайт: выставьте диоптрии **отдельно для левого и правого глаза** (−12…+12) и посмотрите,
как вашу картинку видит каждый глаз — и как её видит человек двумя глазами сразу.

---

## 1. Как выложить на GitHub Pages (5 минут)

1. Создайте **публичный** репозиторий, например `vision-sim`.
2. Загрузите в него файлы: **`index.html`** и **`og-image.png`** (кнопка *Add file → Upload files*).
   `index.html` обязательно должен лежать в корне репозитория. Файл `.nojekyll` тоже полезен — просто оставьте его.
3. `Settings → Pages → Build and deployment → Source: Deploy from a branch`,
   **Branch: `main`, папка `/ (root)`** → *Save*.
4. Через 1–2 минуты сайт будет здесь:
   `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/vision-sim/`

## 2. Включить красивый Embed в Discord

В `<head>` файла `index.html` уже прописаны теги `og:title`, `og:description`, `og:image`,
`twitter:card` и т. д. Осталось вписать адрес сайта: в файле **3 строки** с `YOUR-USERNAME/YOUR-REPO`
(`og:url`, `og:image`, `twitter:image`).

Откройте `index.html` на GitHub → карандаш *Edit* → замените `YOUR-USERNAME/YOUR-REPO` на свой путь:

```
было:   https://YOUR-USERNAME.github.io/YOUR-REPO/
стало:  https://myname.github.io/vision-sim/
```

→ *Commit changes*. Готово: любая ссылка на сайт в Discord будет разворачиваться в карточку
с заголовком, описанием и картинкой `og-image.png` (1200×630).

**Если превью не появилось/старое** — Discord кэширует ответ надолго. Проверяйте так:
отправьте ссылку с параметром `?v=2` (или `?v=3`), либо подождите несколько часов,
либо пересоздайте сообщение в другом канале.

**Требования Discord:** ссылка должна быть публичной (не `localhost`), картинка — по абсолютному
URL, до 8 МБ (у нас 360 КБ). Если позже поменяете домен (свой вместо `github.io`) — поменяйте
адрес в тех же трёх строках.

## 3. Как пользоваться сайтом

- `−` / `+` меняют рефракцию на **0,25 Д**; ползунок — быстрый выбор; клик по числу — **ручной ввод**
  любого значения, например `1,2` (запятая или точка).
- Вкладки: **Как я вижу** (один кадр — восприятие двумя глазами), **Два глаза** (слева/справа),
  **Левый**, **Правый**. Горячие клавиши `1` `2` `3` `4`.
- **Готовые примеры** — норма, близорукость, анизометропия, +1,2 / +1,5 и др.
- **Синхронизировать оба глаза** — двигать оба сразу.
- **Удерживать: оригинал** — показать картинку без искажений для сравнения.
- **Почему + так же?** — справка из двух вкладок:
  1. **Почему + так же?** — схема «куда попадает фокус» при −, 0 и +, формула кружка рассеяния,
     роль зрачка и прищуривания, почему плюсовая линза «увеличивает, но не улучшает»,
     чтение рецепта (Sph / Cyl / Ax / Add) и мини-FAQ.
  2. **Болезни глаз** — 20 состояний в четырёх группах (рефракция, мозг и мышцы, болезни глаз,
     особые случаи): что происходит и как выглядит. У тех, что моделируются (близорукость,
     дальнозоркость, пресбиопия, анизометропия), есть кнопка **«Показать»** — она сразу
     выставляет диоптрии в симуляторе.
- Картинка: «Выбрать файл», перетаскивание в любое место страницы или вставка из буфера (`Ctrl+V`).
  Есть встроенные примеры — фото улицы и таблица букв (11 строк, от огромной «Ш» до совсем мелких,
  без служебных меток). Всё обрабатывается локально в браузере.
- **Параметры модели**: диаметр зрачка (2–8 мм), угловой размер экрана (телефон/ноутбук/телевизор)
  и учёт аккомодации для плюсовых значений.

## 4. Модель размытия

Радиус кружка рассеяния в угловой мере ≈ 0,5 × диаметр зрачка (м) × |диоптрии|.
Угол переводится в пиксели через угловой размер экрана, к диску подбирается эквивалентное гауссово
размытие (σ = r / 1,5), которое рисуется на `<canvas>`.

**Режим «Как я вижу»**: берутся два размытия (для левого и правого глаза) и складываются
как 0,68 × более чёткий глаз + 0,32 × более размытый — грубая модель того, что мозг опирается на
лучший глаз, а второй добавляет «дымку».

Это упрощённая иллюстрация оптического дефокуса: не учитываются астигматизм, аберрации, дифракция,
сетчатка и обработка в мозге. И совсем не медицинская рекомендация.
